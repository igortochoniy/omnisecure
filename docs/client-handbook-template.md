# Your website — quick guide

Your site is live at **[https://domain]**. Here's how to manage it.

## Editing content (the dashboard)

1. Go to **[https://domain/ADMIN-PATH]** (bookmark it — the address is
   deliberately not linked anywhere public).
2. Sign in with **[GitHub / email]**.
3. Edit, then click **Save** — changes go live automatically in **~1–2 minutes**.

**What you can edit:**

- **Blog posts** — write, edit, add new posts, upload cover images, set a post to
  Draft to hide it. New posts get a web address from the title automatically.
- **SEO (page meta)** — the Google title + description for each page.
- **Site settings** — analytics/tracking code, robots, and a global
  "hide from Google" switch (leave OFF once live).
- **Business info** — name, phone, address, hours, ratings (these power your
  Google "business" listing data on the site).
